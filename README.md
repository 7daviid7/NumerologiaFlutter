# **Numerology Desktop Application**

## **Project Description**
This project is a numerology desktop application developed using **Flutter**. The app allows users to explore numerology calculations, understand their meanings, and gain insights based on various numerology principles.

## **Features**
- Input user name and date of birth.
- Calculate key numerology numbers (Life Path, Destiny, Soul Urge, and Personality numbers).
- Detailed explanations of numerology meanings.
- User-friendly interface with a clean design.

## **Technologies Used**
- **Flutter:** Framework for cross-platform development.
- **Dart:** Programming language.
- **Desktop Support:** Windows, macOS, and Linux.
